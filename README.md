# Scrabble Enzo — Solveur & Entraîneur Stratégique ODS8

Solveur et entraîneur stratégique de Scrabble francophone basé sur le lexique ODS8 (411 430 mots).
Comprend :
- Modèle stratégique Anti-Enzo avec évaluation de reliquat centrée (espérance nulle).
- Pénalité de défense pour non-ouverture des cases MT/MD.
- Solveur exact de fin de partie à 2 plis lorsque le sac est vide.
- Modules d'entraînement : Benjamins, Appuis 7+1, Anagrammes, et Préfixes AVO.
- Interface Web interactive locale et CLI unifiée.
